# 0006. 同期は Windows → Immich の一方向とし、ローカルの削除は反映しない

- ステータス: 承認済み
- 日付: 2026-02-21

## 背景

- 写真のバックアップ先として Immich を使う
- ローカルでは容量を空けるためにファイルを消すことがある

## 決定

- 同期は Windows → Immich の一方向のみとする
- Windows 側でファイルを削除・リネームしても、Immich 上のアセットは削除しない
  - Watcher は Remove / Rename イベントを同期対象にしない

## 結果

- 誤ってローカルファイルを消しても、Immich 側の写真は失われない
- Immich 側の整理は、ユーザーが Immich 上で行う
- ローカルの削除を反映するかどうかは、将来オプションにする余地を残している
