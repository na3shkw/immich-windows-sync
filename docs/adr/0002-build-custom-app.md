# 0002. 既存ツールを組み合わせず専用アプリとして実装する

- ステータス: 承認済み
- 日付: 2026-02-21

## 背景

- Windows 上の写真・動画フォルダを、セルフホストの Immich サーバーへ自動同期したい
- Google ドライブのデスクトップアプリのような使用感を目指す

## 決定

- Immich API に直接アップロードする常駐アプリを自作する

## 検討した選択肢

- **Syncthing でサーバーへ同期し、Immich の External Library や CLI で取り込む**
  - Windows → サーバー → Immich の 2 段階になり、Immich への直接アップロードにならない
  - サーバー側にも設定と取り込み処理が必要になる

## 結果

- サーバー側に追加の仕組みは要らない
- 代わりに、次の機能をすべてアプリ側で実装・保守する
  - ファイル監視
  - 重複管理
  - 常駐・自動起動
- 作者の Go 学習の実践題材も兼ねている（[0003](0003-use-go.md)）
