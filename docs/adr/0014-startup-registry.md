# 0014. スタートアップ登録はレジストリの Run キーで行う

- ステータス: 承認済み
- 日付: 2026-06-27

## 背景

- ログイン時にアプリを自動起動したい（[0005](0005-startup-and-tray.md)）
- ユーザーが UI からオン・オフを切り替えられるようにする

## 決定

- `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` に実行ファイルのパスを登録する
- `golang.org/x/sys/windows/registry` を使う
- 値の名前は `appenv.RegistryKey` とし、dev ビルドと本番ビルドで分ける（[0015](0015-dev-prod-build-tags.md)）

## 検討した選択肢

- **レジストリ方式（採用）**
  - Windows アプリで標準的な方法
  - 実行ファイルのパスを 1 つ登録するだけで済む
- **スタートアップフォルダにショートカット（.lnk）を置く**
  - ユーザーがエクスプローラーで直接確認・削除できる利点はある
  - しかし Go で .lnk を作るには COM を呼び出す必要がある
  - その手間に見合うメリットが薄い

決め手は「.lnk の生成が面倒」という点だった。

- dev ビルドと本番ビルドの分離も同じタイミングで検討した
- ただし、どちらの方式でも名前を分ければ対応できるため、方式を選ぶ決め手にはなっていない

## 結果

- HKCU はユーザー単位のキーなので、管理者権限なしで書き込める
- 登録状態は「値が存在するか」で判定できる
  - そのため、UI のトグルに初期状態を反映しやすい
- テストで実際のレジストリを書き換えないよう、レジストリ操作はインターフェースで抽象化している（[0017](0017-testing-with-fakes.md)）
