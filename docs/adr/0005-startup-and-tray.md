# 0005. Windows サービスではなくログイン時起動のトレイ常駐アプリにする

- ステータス: 承認済み
- 日付: 2026-02-21（トレイ常駐・多重起動防止の実装は 2026-09-23）

## 背景

- バックグラウンドで常に同期し続けたい
- 設定画面や状態確認のために UI も必要

## 決定

- Windows サービスではなく、ログイン時に起動する通常のアプリとする
  - 登録方法は [0014](0014-startup-registry.md) を参照
- getlantern/systray でタスクトレイに常駐する
  - ウィンドウの閉じるボタンでは終了せず、ウィンドウを隠す（`beforeClose`）
  - 実際の終了はトレイメニューの「終了」から行う
- Windows の名前付き Mutex で多重起動を防ぐ（`internal/singleinstance`）
  - すでに起動している場合、新しいプロセスは何もせずに終了する

## 検討した選択肢

- **Windows サービス**
  - ログイン前から動ける
  - 開発・デバッグが複雑になる
  - ユーザーごとのフォルダや UI と組み合わせにくい

## 結果

- Google ドライブと同じような使用感になる
- ユーザーがログインしている間しか同期しないことは受け入れる
