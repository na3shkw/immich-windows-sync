# 0016. 設定・DB・ログを %APPDATA% 配下に保存する

- ステータス: 承認済み（DB・同期ログの保存先は [0018](0018-local-data-in-localappdata.md) により置き換え）
- 日付: 2026-03-21

## 背景

- 設定・同期状態 DB・同期ログを保存する場所を決める必要がある

## 決定

- `%APPDATA%\immich-sync\`（Roaming）の下に、次のファイルを保存する
  - `config.json`: 設定（Immich のサーバー URL・API キー、監視対象・除外フォルダ）
  - `syncdata.db`: 同期状態（[0008](0008-assets-table-schema.md)）
  - `sync.jsonl`: 同期ログ（1 件 1 行の JSON）
- 設定ファイルが存在しない場合は、エラーにせずデフォルト値を返す
  - 初回起動は正常な状態として扱う

## 検討した選択肢

- **DB を `%LOCALAPPDATA%` に置く**
  - キャッシュや大きなデータ、マシン固有のデータは Local に置くのが本来は適切
  - DB の中身は端末ローカルのパスと結びついている
  - そのため、将来移すことを検討している（[0018](0018-local-data-in-localappdata.md) で移すことに決定）

## 結果

- アプリのデータが 1 つのフォルダにまとまり、ユーザーが見つけやすい
