# 0003. 実装言語に Go を採用する

- ステータス: 承認済み
- 日付: 2026-02-21

## 背景

- Windows で常駐する同期アプリを、配布しやすい形で作りたい
- アップロードは並行して処理したい

## 決定

- Go で実装する

## 検討した選択肢

- **C#（WPF / WinForms）**
  - Windows との親和性は高い
  - 作者の学習目的と合わない
- **Python（pystray + watchdog）**
  - 最も早く作れる
  - 配布時にランタイムの同梱が必要になる
- **Electron / TypeScript**
  - 配布サイズとメモリ使用量が大きい
- **Rust（Tauri / egui / Slint）**
  - 学習コストが最も高い

## 結果

- シングルバイナリで配布できる
- goroutine とチャネルでアップロードのワーカープールを素直に書ける
- 作者の Go 学習の題材を兼ねる
