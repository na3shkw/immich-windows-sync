# 0013. 監視中に作成された新しいサブフォルダは自動で除外リストに入れる

- ステータス: 承認済み
- 日付: 2026-09-23

## 背景

- 監視対象フォルダの下に、ユーザーが新しくサブフォルダを作ることがある
- その中身を同期したいかどうかは、フォルダによって異なる
- 意図しない写真がアップロードされるのは避けたい

## 決定

- 監視中に新しく作成されたサブフォルダは、自動的に除外リストへ追加する
- 同期したい場合は、ユーザーが Folder Management 画面で除外を解除する

## 検討した選択肢

- **作成時に、同期するかどうかを確認するダイアログを出す**
  - エクスプローラーでのフォルダ作成は、内部的に 2 段階で行われる
    1. 仮の名前（「新しいフォルダー」）で作成する
    2. ユーザーが名前を確定したらリネームする
  - タイミングによってはダイアログが 2 回出てしまうため、採らなかった

## 結果

- 意図しないアップロードを防げる
- 新しいフォルダを同期するには、明示的な操作が必要になる

## 実装上の注意

- `SaveConfig` は、変更前（`a.cfg`）と変更後の設定を比較して Watcher を再起動するか決める
- そのため、`a.cfg` を直接書き換えてから渡してはいけない
  - 比較結果が常に「変更なし」になる
- 新しい `config.Config` を組み立ててから渡すこと
